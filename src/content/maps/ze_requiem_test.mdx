ze_Requiem 是作者 @Seth.（Steam 昵称 @Seth.，主页自述「讨厌猴子」，2017 年 12 月注册）在 CS2 上做的原创僵尸逃跑图，工坊条目标题就是英文的 ze_Requiem，中文社区通称「安魂曲」，条目里同时存在一份只写「version control.」、没有任何简介的镜像版本 ze_requiem_test（工坊 ID 3182845380，同一上传者，2024 年 3 月创建）。本图 2024 年 1 月 7 日上架工坊，抓取时订阅 4758、浏览 4455，文件约 160 MB；由于上架时间在 CS2 僵尸逃跑的早期，它在中文社区被当作「CS2 第一批原创图」之一来看待。

玩法定位是弹幕（bullet hell）图：全程以躲弹幕、躲特效为主要生存手段，因此对光源与粒子特效的观感评价很高——UB 游戏社区的地图点评帖称它「充分向玩家展示了起源 2 引擎下特效效果」，B 站实况也直接以「光效非常酷炫的弹幕图」形容。目前图内共 3 关：前两关为主线流程，第 3 关是 RTV 关（玩家投票才能打到的加演关），工坊简介长期挂着「Stage 3 still working on.」，2025 年 1 月的社区帖也判断后续关卡「咕咕咕了」，即主线第 3 关仍在制作、尚未放出。

神器与 BOSS 方面，GFL 公开的 CS2 配置为这张图登记了两件僵尸道具 Berserker 与 Cone（冷却均为 60 秒），以及两个 BOSS 目标 Hideous 与 Mindflayer，也就是说人类侧没有配置拾取类神器，压力主要来自弹幕与 BOSS 机制。作者在简介里只说明了 RTV 关已加入、第 3 关仍在做，没有公开署名以外的作者信息、推荐人数与难度评级。

社区评价整体偏正面且集中在「好看」与「卡」两点：UB 的点评帖给它「难度适中，RTV 关也不错，就是太烧显卡」；B 站实况同样提到「特效很炫很酷 但 rtv 关的水刀也是真的卡」，RTV 关的水刀（水墙）还有玩家专门去打 1hit 记录。工坊评论区则留下过一些技术反馈，包括第二关「天坠房」前的大飞板 push 上不去、调关房第二关 practice mode 传送点位置错误、以及早期版本容易崩图连控制台一起崩。
