**为什么单独记一份**：站上的内容随时可能因为「作者不希望被收录」「社区有意见」而下架。
删掉之后，如果不留记录，过一阵子没人说得清「这张图为什么没有」、也分不清是漏收录还是被要求下架；
反过来，这份记录也是我们**配合作者与社区**的证据 —— 有人来问，直接看这里。

规则（2026-10-09 起）：

- 作者或社区提出 → **立即下架，不争论**；需要保留解释的，写在这里。
- 下架范围要**连根拔**，别只删页面：条目（`src/content/maps/`）、原稿（`data/research/`）、
  实体分片（`public/entity/data/`）、地形分片（`bake/terr/` + R2 对象、`data/terr-manifest.json`）、
  封面（`public/images/covers/`）、图片集清单（`data/gallery/`）、工坊资料（`data/workshop/`）、
  体积数据（`npm run data:sizes`）、以及 `public/entity/catalog.json` 里的条目
  （⚠️ `build-catalog.mjs` 会保留历史条目，**光删分片不够**，必须同时剪索引）。
- 如果该图已被链接到（例如写进了某条攻略），构建时的 `npm run content:links` 会报死链 —— 一并清掉。
- 下架前把删掉的文件备份一份到仓库外（`%TEMP%\bak-*`），万一聊清楚要恢复，不用重新烘。
